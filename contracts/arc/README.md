# Arc contracts

`WorkingCapitalFacility.sol` is an illustrative starter for the core borrowing-base, reservation, and repayment invariants. It has not been generated or reviewed in Arc Studio, compiled, audited, or deployed. The final Arc prize submission must be created in Arc Studio and record the Studio project URL plus verified deployment addresses.

Before live use, replace the owner-only settlement boundary with verified coordinator attestations, an explicit lender allocation ledger, per-agent reservation accounting, safe ERC-20 handling, pause controls, and adversarial tests.
